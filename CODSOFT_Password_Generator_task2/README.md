# CodSoft Python Internship - Password Generator

## 📌 Project Description
This project generates a secure random password based on the length entered by the user.

The generated password includes:
- Uppercase letters (A-Z)
- Lowercase letters (a-z)
- Numbers (0-9)
- Special characters (!@#$%^&* etc.)

## 🚀 Features
- User chooses password length
- Ensures strong password generation
- Uses Python's built-in `random` and `string` modules
- Handles invalid input
